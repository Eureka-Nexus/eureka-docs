1. Foundation — domain, GitHub, protocol, miner/server, website.
2. Mining release — desktop UI, final CPU/GPU PoW, difficulty, signed builds.
3. EKNX Mainnet — create fixed supply, distribute allocations, tiny real payout test.
4. Public launch — miner, dashboard, community, Bitcointalk, market/liquidity.
5. Eureka 1.0 — future AI Agent and additional EKNX utility.
