# EKNX Tokenomics

Maximum supply: **100,000,000 EKNX**.

Year-1 mining ceiling: **800,000 EKNX**. CPU: 480,000. GPU: 320,000.

CPU target at 10-minute rounds: approximately **9.132420 EKNX per CPU round**.

EKNX mining is not Solana consensus mining. The Eureka network records verifiable work and later transfers existing EKNX from the Mining Reserve to miners' Solana token accounts.

No future market price is guaranteed.
