# BSC contract reference

This directory contains the local source snapshot, public ABIs and deployment addresses used by the BSC integration. Solidity files retain their SPDX license declarations. No private keys or transaction-signing configuration is included.

Recorded compiler: `0.8.36+commit.8a079791`; optimizer 500 runs; via IR; OpenZeppelin Contracts 5.6.1. `SOURCE_SHA256.json` records the source file hashes. This snapshot is not a claim of explorer verification or an independent audit; deployed-bytecode equivalence must be verified before the launch gate is closed.

`bsc-mainnet.json` contains public addresses and the deployment transaction only. Query current contract state; a deployment manifest is not live status.
